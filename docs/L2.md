Overview
LLMs & Agentic AI: From Visual Foundations to Your First AI Agent
 

A practical, end-to-end course that demystifies how large language models work, surveys the fast-moving open-source landscape, teaches the Model Context Protocol (MCP), and walks you through modern agentic patterns—culminating in a hands-on build where you create and evaluate your own tool-using AI agent.

 

Who this course is for
Software engineers, QA Engineers, data scientists, and makers shipping AI features.

Product and technical leaders who need a working grasp of LLM capabilities, trade-offs, and costs.

Curious learners who want to move from “prompting” to building reliable, tool-using agents.

Prerequisites
Comfortable with basic Python or JavaScript.

Familiarity with APIs and the command line.

GPU not required; cloud and CPU-friendly paths provided.

What you’ll be able to do by the end
Explain—in plain language—how transformers, attention, and “inference” actually work.

Choose the right model (and size) for quality, latency, price, or privacy constraints.

Run open-source models locally and via a hosted low-latency provider.

Stand up an MCP server and connect tools safely to your models.

Design agent workflows (reflection, planning, tool use) with guardrails and evals.

Ship a minimum-viable agent that performs a useful task end to end.

Syllabus & Detailed Module Descriptions
1) Inside LLMs (A Visual Guide)
Give your mental model an upgrade with intuitive, picture-first explanations.

2) Open-Source Model Landscape
Make grounded choices in a noisy market.

3) Deep Dive: Model Context Protocol (MCP)
Connect tools to your models safely and consistently.

4) AI Agents
Foundations you’ll actually use in production.

5) Agentic AI
6) Hands-On: Building Your First Agent
Create Your Agent
Capstone lab: you’ll build a goal-directed agent that uses MCP tools (e.g., web retrieval, a knowledge base, and a task runner). You’ll add reflection, define stop conditions, instrument logs, and run a small evaluation to ensure your agent is safe, reliable, and cost-aware.

Format & Time Commitment
Format: Visual lectures, readings, guided labs, and a capstone build.

Effort: ~10–15 hours total, depending on how deep you go on the capstone.

Deliverables: Local and hosted model demos, a working MCP server, and a production-ready agent.

Tooling & Setup
Python/Node environment, CLI access.

Local run path (CPU or GPU) and hosted path (e.g., Groq endpoint).

Starter repos and copy-pasteable snippets for each lab.

Assessment & Certification
1 graded quiz + auto-checked lab checkpoints.

Capstone rubric covering correctness, robustness, observability, and cost.

Certificate of completion upon successfully submitting the capstone.

Outcomes in Practice
Learners leave with a clear mental model of LLM mechanics, the ability to choose and deploy open-source models wisely, hands-on MCP experience, and a working agent they can extend for real product use cases.
