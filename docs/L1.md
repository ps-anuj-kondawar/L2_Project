Level: Beginner → Early-intermediate
Audience: Software engineers, data/ML practitioners, product/tech leads, project managers starting with LLMs, RAG, agents, and MCP.
Prerequisites:

Comfortable with basic programming concepts and APIs

High-level understanding of cloud/dev tools (CLI, repos)

Course Description (short):
A practical, hands-on introduction to building with Large Language Models. You’ll learn how LLMs work, how to design prompts and context, when to use RAG vs. fine-tuning, how vector search powers retrieval, and how agents integrate with tools via MCP. The course culminates in a guided lab where you ship a minimal RAG assistant.

Learning Outcomes (you will be able to):

Explain how LLMs process tokens, context windows, and parameters.

Design effective system and user prompts with clear guardrails.

Build retrieval pipelines (chunk → embed → retrieve → generate) and reason about vector DB choices.

Choose appropriately between prompting, RAG, and fine-tuning for a use case.

Understand agent/tool integration patterns and risks (incl. MCP).

Deliver a small, working RAG assistant with grounded, cited answers.

Format & Materials:

12 micro-lessons (videos + readings) and 1 capstone lab

Each lesson includes Why it matters, Outcomes, and Quick checks

Estimated Effort: ~8–11 hours total (self-paced)

Core lessons: ~6–8 hrs

Capstone lab: ~2–3 hrs

Assessment & Completion:

Quick-check responses after each lesson (self-graded or mentor-reviewed)

Capstone submission: working demo + short write-up

Completion = all quick-checks + passing capstone + Quiz
