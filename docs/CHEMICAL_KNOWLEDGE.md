# Chemical Knowledge & Regulatory Reference Guide

> **Maintainer note**: This document is the single reference for all chemical limits, regulatory standards, and hazard classifications used by ChemShield AI. Any change to a regulatory limit in `src/core/constants.py` or `src/utils/ghs_rules.py` must be reflected here with its source citation.

---

## Unit Semantics — Critical Understanding

ChemShield AI works with two fundamentally different concentration units. Confusing them leads to scientifically invalid compliance verdicts:

| Unit | Meaning | Context | Example |
|------|---------|---------|---------|
| `ppm` (parts per million) | Airborne vapor concentration | Worker inhalation safety monitoring | "Air contains 200 ppm Toluene" |
| `%` (percent v/v or w/w) | Liquid formulation composition | Mixture ingredient composition | "Formula contains 6% Benzene by volume" |

**These are different physical quantities and cannot be directly compared.**

When a user provides `6% Benzene` and the OSHA limit is `1 ppm TWA`, the system correctly flags this as `REVIEW_REQUIRED` — not `NON_COMPLIANT` — because the comparison is scientifically undefined. A professional certified safety professional (CSP) must determine the airborne concentration generated by the liquid formulation at the use conditions.

## OSHA Exposure Limit Types

ChemShield tracks four types of airborne exposure limits:

| Field | Full Name | Definition |
|-------|-----------|------------|
| `pel_ppm` | Permissible Exposure Limit (8-hr TWA) | Maximum average airborne concentration over an 8-hour workday. The legally enforceable OSHA limit under 29 CFR 1910.1000. |
| `stel_ppm` | Short-Term Exposure Limit (15-min) | Maximum airborne concentration for any 15-minute period (max 4 times/day). Not all chemicals have STELs. |
| `ceiling_ppm` | Ceiling Value | Must not be exceeded at any time. Used for chemicals with immediate acute toxicity (e.g., Chloroform). |
| `action_level_ppm` | Action Level | Concentration that triggers mandatory air monitoring and medical surveillance programs. Typically 50% of PEL. |

## GHS Hazard Statement Reference

The GHS (Globally Harmonized System) uses standardized H-codes to describe hazards. ChemShield uses H-codes to determine signal words and GHS pictograms.

**DANGER signal word trigger codes** (Category 1 or 2 hazards):

| Code | Hazard Description |
|------|--------------------|
| H224, H225 | Extremely/Highly Flammable Liquid |
| H300, H310, H330 | Acute Toxicity Category 1-2 (Oral, Dermal, Inhalation) |
| H314 | Causes Severe Skin Burns and Eye Damage |
| H334 | May Cause Allergy or Asthma |
| H340 | May Cause Genetic Defects |
| H350 | May Cause Cancer |
| H360 | May Damage Fertility or the Unborn Child |
| H370 | Causes Damage to Organs (single exposure) |

All other H-codes trigger the **WARNING** signal word.

## CAS Number Format & Resolution

ChemShield supports CAS (Chemical Abstracts Service) Registry Numbers as chemical identifiers.

- **Format**: `XXXXXXX-YY-Z` where X = 2-7 digits, Y = 2 digits, Z = 1 check digit
- **Validation**: Check digit is computed by the weighted sum algorithm defined by CAS
- **Resolution**: When a CAS number is entered, it is resolved to a chemical name using `CAS_TO_NAME` in `src/core/constants.py`
- **Fallback**: If the CAS number is not in the local map, it is passed to PubChem for resolution

**Supported CAS → chemical name mappings** (22 entries in `CAS_TO_NAME`):

## Data Retrieval Hierarchy

When evaluating a chemical, ChemShield queries the following sources in priority order:

1. **MASTER_CHEMICAL_DATABASE** (hardcoded, always authoritative)
2. **ChromaDB RAG** (embedded OSHA regulatory text chunks)
3. **SQLite cache** (previously fetched regulatory limits)
4. **Gemini API chemical lookup** (direct AI knowledge query)
5. **Tavily web search** (live fallback for exotic compounds)

A chemical returns `UNKNOWN` status only if none of these 5 sources yield a limit value. This is intentional **fail-closed** behavior — unknown does not equal safe.
